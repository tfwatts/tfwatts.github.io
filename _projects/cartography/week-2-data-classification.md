## Overview

This project presents four thematic maps of the contiguous United States, each displaying a different variable: change in unemployment rate, percentage of rural population, U.S. regions, and total population. The goal was to match each map’s classification method and color scheme to the underlying data type; sequential, diverging, or qualitative. For example, unemployment change uses a diverging scheme anchored at zero to separate rising from falling rates, while regions use a qualitative palette with no implied order. Together, the maps show how thoughtful cartographic choices make each dataset easier to read and interpret.
